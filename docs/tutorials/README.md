# Tutorials

Seven task-oriented walkthroughs. Each one starts from a working install and ends with something you can check.

| Tutorial | You will end up with |
|---|---|
| [first-5-minutes](first-5-minutes.md) | a gateway answering, a dashboard open, one real turn in the ledger |
| [connect-a-coding-tool](connect-a-coding-tool.md) | Cline / Continue / Cursor / Aider pointed at Sui, with the config it wrote |
| [build-a-free-agent](build-a-free-agent.md) | a small script that uses three free routes and survives one of them failing |
| [understand-routing](understand-routing.md) | you can predict which provider answers, and explain why |
| [red-team-your-own-routes](red-team-your-own-routes.md) | a report showing whether your routes obey an injected instruction |
| [self-host-for-a-team](self-host-for-a-team.md) | one gateway, per-key budgets, a vault for paid keys |
| [troubleshooting-doctor](troubleshooting-doctor.md) | you can diagnose a 503, a 429, a resting provider and an empty answer |

Prerequisites for all of them: Node 20+, and the repository cloned (`git clone https://github.com/drsamonline/sui && cd sui && npm install`).
