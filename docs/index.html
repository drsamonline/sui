Install

Node 20 or newer. No runtime dependencies, no build step. Not yet on npm — clone it and run the source.

git clone https://github.com/drsamonline/sui
cd sui && npm install
node apps/cli/bin/sui.js init

Then point anything that speaks OpenAI at http://127.0.0.1:8787/v1. The first run ends with a real round-trip, not a green tick.

What it does

Routing

  • OpenAI-compatible endpoint, streaming and not
  • Four strategies: fallback, weighted, cheapest, latency
  • Per-target circuit breaker, three states
  • Budgets per day and per provider
  • Two-tier cache: exact, plus lexical similarity
  • Quota-aware prompt compression, six engines, code preserved

Trust

  • Paid air-gap: gate in code, vault sealed with AES-256-GCM
  • tos: avoid is never auto-routed
  • Prompts hashed, never stored
  • Host-header allowlist, SHA-256 API keys
  • WCAG AA verified numerically on every token pair

Operating it

  • Dashboard: budget, topology, breaker states, prompt-free usage
  • Ledger with cost, latency, first token, cache, verification
  • CSV export, gzip via compress-kit
  • Onboarding that detects your tools and writes their config
  • Migration from another router with a preview diff

Proving it

  • 50-prompt golden set, nine deterministic graders
  • Self-test that proves the graders grade
  • Soak harness gating p95 against a 15 ms budget
  • Invariant table: statement, enforcer, test
  • Regression gate on every PR

Honest limits

Not built yet

  • No catalogue entry has a resolved endpoint, so nothing is verified yet
  • No first-chunk clone: a mid-stream drop is reported, never spliced
  • No MCP, no red-team self-test, no cache-aware compression
  • No tenant console or per-user cost attribution
  • No npm package; run from source

Stated plainly

  • The vault passphrase sits beside the vault unless you supply SUI_VAULT_PASSPHRASE
  • The lexical cache tier is lexical, not semantic
  • Upstream kit licences still read PolyForm NC
  • Mid-stream failures are reported, never spliced
