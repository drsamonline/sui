Install

Node 20 or newer. No runtime dependencies, no build step. Not yet on npm, so npx has nothing to download — clone it and run the wrapper that ships with the code.

git clone https://github.com/drsamonline/sui
cd sui && npm install

# macOS / Linux
./sui

# Windows (PowerShell or CMD)
.\sui.cmd

That is the whole setup: the wrapper runs the source directly, no global install. Want a sui command anywhere? npm link once. Then point anything that speaks OpenAI at http://127.0.0.1:8787/v1 — the first run ends with a real round-trip, not a green tick. Windows guide · cURL, Node, Python, PHP.

What it does

Routing

  • OpenAI-compatible endpoint, streaming and not
  • Four strategies: fallback, weighted, cheapest, latency
  • Per-target circuit breaker, three states
  • Budgets per day and per provider
  • Free-first ordering: a free target outranks a paid one, always
  • Speculative cascade: a 50 ms classifier picks cheap or strong
  • Quota windows: a 429 with Retry-After closes a target for exactly that long
  • Fallback learning from measured health, not declared order
  • Two-tier cache: exact, plus lexical or hashed-vector similarity
  • Quota-aware prompt compression, seven engines, code preserved
  • Savings ledger: dollars avoided, tokens never sent
  • Verification escalation: weak answers are never called verified
  • Explain-my-route, in sentences, without sending a request
  • Red-team self-test: 11 obfuscations, a random canary per run
  • Native prompt caching: the hint each provider understands
  • Grounding check: a claim that is not in the context costs confidence
  • Residency: a request can require a region, and an unmarked provider never satisfies it

Trust

  • Paid air-gap: gate in code, vault sealed with AES-256-GCM
  • tos: avoid is never auto-routed
  • Prompts hashed, never stored — and health history has no field for one
  • Host-header allowlist, SHA-256 API keys, constant-time comparisons
  • Bounded runs: spend, steps, time and loop limits per agent run
  • Two-plane split: the agent-facing half holds no provider key
  • Owner licence grant, enforced by a test
  • WCAG AA verified numerically on every token pair

Operating it

  • Dashboard: budget, savings, free-tier weather, topology, breaker states
  • Ledger with cost, latency, first token, cache, verification
  • CSV export, gzip via compress-kit
  • Onboarding that detects your tools and writes their config
  • Migration from another router with a preview diff
  • MCP server over stdio and HTTP, and MCP servers as providers
  • Recipes: five named setups that never overwrite your work
  • sui local finds a model server on this machine
  • Drift detection (EWMA + CUSUM) and trend history on disk
  • Tenant console: what each key spent, and what it may reach
  • Bounded runs: spend, steps, time and loop limits per agent run
  • Sandbox: sui sandbox, a separate process, 14-case attack suite
  • Two-plane split: the agent-facing half holds no provider key

Proving it

  • 50-prompt golden set, nine deterministic graders
  • Self-test that proves the graders grade
  • Soak harness gating p95 against a 15 ms budget
  • Invariant table: 19 statements, each with an enforcer and a test
  • Two audits in the repository, with accepted risks stated
  • Regression gate on every PR

Honest limits

Not built yet

  • No catalogue entry has a resolved endpoint, so nothing is verified yet
  • No first-chunk clone: a mid-stream drop is reported, never spliced
  • No tenant console or per-user cost attribution
  • No npm package; run from source

Stated plainly

  • The vault passphrase sits beside the vault unless you supply SUI_VAULT_PASSPHRASE
  • The lexical cache tier is lexical, not semantic
  • Upstream kit licences still read PolyForm NC
  • Mid-stream failures are reported, never spliced
